## Getting Started

First, download the repository and enter its directory:

```bash
git clone https://github.com/gabefofemiller3465/activity-scraper-web.git
cd REPO
```

Activity Scraper is a web project, so you can open its primary HTML file in a browser. If direct file access is not sufficient, run the repository through a local web server instead.

For example:

```bash
python3 -m http.server 8000
```

Open the following address after starting the server:

```text
http://localhost:8000
```
